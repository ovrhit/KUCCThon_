# 한편

> 작은 감사들이 쌓여,
> 하나의 메시지가 됩니다.

한편은 감사의 마음을 기록하는 서비스입니다.

사용자는 매일,
특정 사람에게 전하고 싶은 짧은 메시지를 남깁니다.

- 최대 10초의 짧은 영상
- 한 줄의 메시지
- 하루의 작은 감사

그리고 그 기록들은 시간순으로 쌓여,
한 사람만을 위한 하나의 reel이 됩니다.

부모님에게,
친구에게,
연인에게,
혹은 미래의 나 자신에게.

우리는 거창한 이벤트보다,
매일의 작은 감사에 집중했습니다.

---

# Core Concept

감사는 보통 순간적으로 지나갑니다.

- “오늘 데리러 와줘서 고마웠어”
- “오늘 같이 있어줘서 고마워”
- “별거 아니었지만 힘이 됐어”

한편은
그 짧은 감사들을 하루씩 기록하고,
시간이 지나 하나의 메시지로 이어줍니다.

---

# MVP Features

## 1. Daily Gratitude Log

특정 사람에게 전하고 싶은 감사의 메시지를 기록합니다.

### Record
- 최대 10초 영상 업로드
- 짧은 메시지 작성
- 대상 선택
  - 부모님
  - 친구
  - 연인
  - 나 자신

---

## 2. Replay Reel

기록된 영상들은 시간순으로 자동 연결됩니다.

사용자는:
- 하루
- 일주일
- 한 달
- 1년

동안 쌓인 감사의 기록을
하나의 reel처럼 감상할 수 있습니다.

### Replay Experience
- vertical reel UI
- autoplay
- fade transition
- 날짜 기반 흐름
- fullscreen mobile experience

---

## 3. Calendar

언제 감사를 기록했는지 확인할 수 있습니다.

### Calendar Features
- 기록한 날짜 표시
- 날짜별 gratitude log 확인
- monthly overview
- 기록 흐름 시각화

---

## 4. Share

완성된 gratitude reel을
특정 사람에게 링크로 공유할 수 있습니다.

상대는 웹에서 바로
감사의 기록들을 이어서 감상할 수 있습니다.

---

# Why

감사는 대부분 짧게 지나갑니다.

하지만 그 짧은 순간들이 쌓이면,
한 사람에게는 오래 남는 기억이 됩니다.

한편은
매일의 작은 감사들을 기록하고,
시간의 흐름으로 전달합니다.

# 로컬 개발 및 테스트 가이드

이 프로젝트는 별도의 백엔드 연동 없이 UI와 컴포넌트를 바로 테스트할 수 있도록 초기 Mock 데이터가 포함되어 있습니다.

## 1. 프로젝트 실행 방법

저장소를 클론하거나 코드를 다운로드 받은 후, 아래 명령어를 순서대로 실행하세요.

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

서버가 실행되면 브라우저에서 `http://localhost:3000`으로 접속하여 앱을 확인할 수 있습니다.

## 2. 화면별 테스트 가이드

현재 목업(Mock) 데이터가 적용되어 있어 주요 흐름을 확인할 수 있습니다. 모바일 환경에 최적화되어 있으므로 브라우저의 **개발자 도구(F12)에서 모바일 뷰로 전환**하여 테스트하는 것을 권장합니다.

- **홈 (`/`)**: 최근 작성된 감사 기록 리스트를 확인하고 하단 네비게이션을 테스트합니다. 우측 하단의 `+` 버튼을 눌러 기록 화면으로 이동할 수 있습니다.
- **기록 페이지 (`/record`)**: 대상(부모님, 친구 등)을 선택하고 메시지를 입력하는 폼 UI를 확인합니다.
- **릴스 리플레이 (`/replay/all` 또는 `/replay/[id]`)**: 세로형 영상 플레이어의 UI 구조와 메시지 오버레이를 확인합니다. (현재는 Mock 텍스트만 표시됩니다.)
- **캘린더 (`/calendar`)**: 월별 기록 일자가 달력 형태의 그리드에 어떻게 표시되는지 확인합니다.
- **공유 페이지 (`/share/sample-id`)**: 링크를 통해 접속했을 때 보여지는 랜딩 페이지 UI를 확인합니다.

## 3. Mock 데이터 수정

UI에 표시되는 초기 데이터는 `lib/mockData.ts` 파일에서 관리하고 있습니다. 다른 케이스를 테스트하고 싶다면 해당 파일의 배열 데이터를 수정하면 즉시 화면에 반영(HMR)됩니다.
