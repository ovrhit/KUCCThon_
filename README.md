# 한편

> 작은 감사들이 쌓여, 하나의 메시지가 됩니다.

**한편**은 특정 사람에게 전하고 싶은 짧은 감사 기록을 영상과 메시지로 남기고,  
그 기록들을 시간순으로 모아 하나의 세로형 릴스처럼 보여주는 웹 서비스입니다.

부모님에게, 친구에게, 연인에게, 혹은 미래의 나 자신에게  
매일의 작은 감사를 한 편의 메시지로 전달하는 것을 목표로 합니다.

---

## 핵심 아이디어

감사는 보통 순간적으로 지나갑니다.

- “오늘 데리러 와줘서 고마웠어”
- “오늘 같이 있어줘서 고마워”
- “별거 아니었지만 힘이 됐어”

한편은 이런 짧은 감사들을 하루씩 기록하고,  
시간이 지난 뒤 한 사람만을 위한 하나의 영상 메시지로 이어줍니다.

---

## 주요 기능

### 1. 보관함 기반 홈 화면

- 감사 기록을 남길 대상을 리스트 형태로 표시
- 예: 나 자신, 부모님, 친구, 연인
- 각 대상별 상세 페이지로 이동
- 각 대상별 즉석 기록 페이지로 이동

### 2. 대상별 기록 페이지

- 특정 대상에게 남긴 기록을 캘린더 형태로 확인
- 기록이 있는 날짜를 시각적으로 표시
- 해당 대상에게 새 기록을 남기는 버튼 제공

### 3. 감사 기록 작성

- 대상 선택
- 감사 메시지 작성
- 짧은 영상 업로드
- 기록 저장

### 4. Replay Reel

- 대상별 감사 기록을 시간순으로 재생
- 세로형 릴스 UI를 목표로 구현

### 5. 공유 기능

- 완성된 릴스를 공유 링크로 전달하는 기능을 목표로 구현
